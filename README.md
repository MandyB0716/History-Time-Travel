# CS630 Final Project: History Time Travel - Educational Interactive Website

## 📌 Project Overview
This interactive web application was developed as a final academic project for the MS in Applied Computer Science program at Southeast Missouri State University. Designed specifically for a target demographic of children ages 5-8, the platform explores human-computer interaction (HCI) principles through a gamified, educational approach to history. 

The core objective is to teach early learners about different historical eras through immersive storytelling, engaging UI, and chronological navigation. The curriculum is meticulously structured into 10 distinct historical eras. Each era acts as a complete scenario, featuring 3 bite-sized lessons that culminate in an interactive quiz (totaling 30 lessons and 10 quizzes) to maximize knowledge retention and prevent cognitive overload.

## ✨ Features
* **10 Interactive Historical Eras:** Users navigate through different periods in history. Each era is broken down into structured lessons and an interactive quiz to reinforce learning.
* **Targeted HCI Focus:** Implements age-appropriate storytelling, immersive feedback, and intuitive chronological navigation designed for early childhood cognitive development.
* **Responsive Layout:** A clean, attractive graphical user interface (GUI) optimized for various screen sizes, utilizing friendly animations to encourage positive learning experiences.
* **Real-time Feedback:** Provides instant, constructive feedback after quizzes to maintain engagement and prevent negative feelings during the learning process.

## 🛠️ Repository Structure

## 💻 Local Installation & Setup
To run the source code locally for evaluation or testing:

1. Clone the repository (this will default to the `main` branch containing the code):
   ```bash
   git clone [https://github.com/mandyb0716/CS630_Final_Project.git](https://github.com/mandyb0716/CS630_Final_Project.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd CS630_Final_Project
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm run dev
   ```
